## 🎯 Center

A handle to center a UI element in its parent in one click.

### How to use

1. Select a UI element.
2. A handle appears above the element.
3. Click it.

The element is placed at the center of its parent (`Position` set to `0.5, 0.5` and adjusted with its `AnchorPoint`, so it is really centered). You can undo it with `Ctrl + Z`.

You can turn it off in the [Shortcuts](Shortcuts.md) window (**Center**).
