## 🔃 Rotate

A handle to rotate a UI element with the mouse, instead of typing a `Rotation` value.

### How to use

1. Select a UI element.
2. A rotation handle appears next to the **top-left corner** of the element.
3. Drag the handle to rotate the element.

The handle follows the element when you move, resize or rotate it.

You can turn it off in the [Shortcuts](Shortcuts.md) window (**Rotate button**).
