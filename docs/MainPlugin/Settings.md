## ⚙️ Settings

Click the **gear** at the top right of the plugin window to open the settings.

It contains 3 sections:

| Section | Description |
|---|---|
| **Theme** | Choose the look of the plugin. |
| **Help** | Quick help and useful links. |
| **Donate** | A link if you want to support the plugin. |

When a new version of the plugin is available, a notice is displayed in the main window. Click the close button to hide it.

To turn on or off the helpers displayed on the canvas (Rotate, Center, QuickAction, Vectors), see [Shortcuts](MoreTools/Shortcuts.md).
