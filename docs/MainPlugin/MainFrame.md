## Main Frame


You can open the main frame by clicking here:

 ![LOGO](mainframe.png).

 The **MainFrame** includes 8 tabs : 

 1. [Tween](Frames/Tween/Tween.md)
 2. [Auto-Scale](Frames/Auto-Scale.md)
 3. [Auto-Script](Frames/Auto-Script.md)
 4. [Asset](Frames/Asset.md)
 5. [One-TopBar](Frames/One-TopBar.md)
 6. [Texture](Frames/textureframe.md)
 7. [Icon](Frames/Icon.md)
 8. [More-Tool](MoreTools/MoreTools.md)

and a Settings Frame
[Settings](Settings.md)

The [Vector Creator](Vector.md) is opened with the **Add Vector** button that appears when you select a `Frame`.
